# Atlas Maps (Phase 1)

```bash
cd apps/mobile
npm install
npx expo start
```

Long-press the map to drop a pin. Upload a photo as the pin icon (MapLibre style images + SymbolLayer). Pins list: tap a row to fly the camera. Folders and icons persist in SQLite under the app document directory.
MapLibre demo style is online until offline packs land in Phase 3.
