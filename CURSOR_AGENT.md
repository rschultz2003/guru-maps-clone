# Cursor Cloud Agent brief — Phase 1 MVP

Repo: https://github.com/rschultz2003/guru-maps-clone

Build an Expo (React Native) TypeScript app named Trail Pin.

Implement:
1. Expo Router scaffold.
2. MapLibre map with OSM-based style and OSM attribution.
3. Long-press to create a pin at that coordinate.
4. Custom icon upload (image picker) stored on device and shown as the pin icon on the map. This is the product differentiator — make it obvious and reliable.
5. Default icon set if no upload.
6. Folders: create/list/assign/toggle visibility.
7. SQLite persistence so pins/icons/folders survive relaunch.
8. User location permission + puck on the map.

Read README.md and PLAN.md first. Do not implement CarPlay, subscriptions, or full offline country packs in this PR.

Open a PR with the working MVP scaffold.
